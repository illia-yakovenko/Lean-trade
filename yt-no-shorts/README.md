# YT No Shorts

Вырезает YouTube Shorts из мобильного (m.youtube.com) и десктопного веб‑YouTube:
полки Shorts на главной, в поиске и рекомендациях, вкладку Shorts в нижней панели,
чипсы‑фильтры «Shorts», вкладку на каналах. Любая ссылка `/shorts/ID` открывается
как обычное видео `/watch?v=ID`.

> ⚠️ **Chrome для Android не поддерживает расширения вообще** — ни из магазина, ни вручную.
> Поэтому ниже три способа; выбирай по вкусу.

## Способ 1 — прямо в Chrome: букмарклет (без установки)
1. Скопируй всё содержимое `dist/bookmarklet.txt` (начинается с `javascript:`).
2. Chrome → ⋮ → ☆ (добавить закладку) → ⋮ → «Закладки» → карандаш на новой закладке:
   - Название: `noshorts`
   - URL: вставь скопированное.
3. Открой m.youtube.com, тапни в адресную строку, набери `noshorts` и выбери закладку
   из подсказок (именно со значком закладки).

Работает до перезагрузки страницы (навигация внутри YouTube не сбрасывает).
После перезагрузки/нового входа — снова `noshorts`.

## Способ 2 — навсегда: Firefox для Android + uBlock Origin (рекомендую)
1. Поставь Firefox из Play Store, в нём — дополнение **uBlock Origin**.
2. uBlock Origin → Панель управления → «Мои фильтры» → вставь `dist/ublock-filters.txt` → «Применить».

Или вместо uBO: дополнение **Tampermonkey** → установить `dist/yt-no-shorts.user.js`
(там ещё и редирект шортсов в обычный плеер).

## Способ 3 — Chromium‑браузер с расширениями
Lemur Browser, Quetta, Yandex Browser и т. п. умеют ставить расширения.
Ставь `dist/yt-no-shorts-extension.zip` (или папку `dist/extension`)
через их меню расширений («загрузить из файла / распакованное»).
Это обычное Manifest V3 расширение — работает и в десктопном Chrome.

## Сборка
Исходник один — `src/core.js`. `node build.js` генерирует всё в `dist/`.
Если YouTube поменяет вёрстку и что‑то вылезет — селекторы в начале `src/core.js`.
